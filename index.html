烘焙百科
先讲逻辑，再记名字

恰巴塔、布里欧修、丹麦酥……名字再怪，也不过是几个变量的组合：什么基底、靠什么膨松、放多少油、怎么烤熟。先像程序员一样把变量声明清楚，36 种烘焙品就不是 36 个孤立的名字，而是同一套变量的不同取值——忘了名字没关系，变量不会骗你。

第一课

先声明变量：烘焙品是一种「类型」

程序员不会背 36 个孤立的名字，而是先定义变量、再看组合。下面这 6 个变量就是烘焙世界的「类型系统」：本站每个词条，都是给这 6 个变量各赋一个值。赋值定了，它是什么、和谁是亲戚，立刻清楚。

type 基底 base = 精简面团 | 油润面团 | 开酥面团 | 面糊 | 烫面团 | 酥粒面团 | 蛋白霜糊 // 它是用什么做的 type 膨松 leaven = 酵母 | 天然酵种 | 化学膨松 (泡打粉) | 蛋液打发 | 蒸汽 | 无 // 里面的气从哪来 type 油脂 fat = 无 | 少量 | 中等 | 高 // 配方有多「富」 type 熟成 heat = 烘烤 | 平底烙 | 先煮后烤 | 免烤冷藏 | 烤后组装 // 最后怎么定型 type 门类 cat = 面包 | 蛋糕 | 酥点 // 独立变量：看形态与用途 // cat 不是派生量，推不出来：同为「油润面团 + 酵母」， // 成型当主食的是面包（布里欧修、佛卡夏），卷成小个甜点的 // 却是酥点（肉桂卷）——起决定作用的是形态与用途； // 产地 origin 只负责命名——所以名字最不可靠，变量最可靠。
可颂 = 开酥面团 + 酵母 + 高油脂

基底决定工艺（裹油折叠 27 层），膨松决定内部（酵母产气撑开蜂窝），油脂决定香气。三个变量一报，可颂的全部身份就说完了。

戚风 = 面糊 + 蛋液打发 + 中等油脂

没有酵母、没有泡打粉，气全靠蛋白霜。油用的是植物油而不是黄油——这一个取值之差，就是它比海绵蛋糕湿润不噎人的全部原因。

提拉米苏 = 面糊 + 无膨松 + 免烤冷藏

膨松取「无」、熟成取「免烤」——它根本不进烤箱，靠冷藏凝固。在类型系统里，它是离面包最远的那一个极端。

派生关系：很多「新名字」只是老类型的改款

丹麦酥 = 可颂 + 馅料 + 造型变量全同，只多一步加馅——它是可颂的「子类」，不是新物种。
戚风 = 海绵 + 植物油 + 分蛋法在海绵的公式上改两个取值，就得到一个新名字。看懂 diff，就不用重背。
英式马芬 ≠ 美式马芬同名，但 6 个变量几乎全不同（面团 vs 面糊、酵母 vs 泡打粉、烙 vs 烤）。靠名字分类必翻车，靠变量不会。
第二课

变量查询台：自己组一组，看命中谁

给每个变量选一个值，条件之间是「并且」（AND）——命中的，就是同时满足全部条件的烘焙品。这正是数据库查询的逻辑：不背名单，按条件捞。

这个组合在 36 种经典品类里不存在——说明这组变量取值现实中没人这么搭，换一组试试。
